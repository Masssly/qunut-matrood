# Text review log

## Current status

The supplied file, **Dua Al-Qunut - Abdallah Muhammad Al Matrood**, is a 22-page image-based PDF. It contains a Latin-script rendering/transliteration of the recitation, not selectable text. OCR can provide a rough working aid but is not reliable enough to publish as the final text.

The website intentionally does not present an unverified transcript as authoritative.

## Review workflow

- [ ] Preserve the original PDF as the reference source in the project archive.
- [ ] Transcribe each page, keeping page boundaries for checking.
- [ ] Compare every line with the PDF image.
- [ ] Compare wording and repetitions with the supplied YouTube recitation: https://www.youtube.com/watch?v=DBngjJNK_nQ
- [ ] Mark uncertain words instead of guessing.
- [ ] Decide whether the reading text should be Arabic script, the supplied Latin-script transliteration, or both.
- [ ] If Arabic script is added, have it checked by a competent Arabic reader.
- [ ] Keep any translation as a separate, clearly attributed layer.
- [ ] Generate a print-friendly PDF only after the text has been reviewed.

## Important distinction

The PDF and the YouTube recording are separate sources. Do not silently change the PDF text to match a guess based on the recording. Record differences and resolve them explicitly during review.
