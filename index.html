About this edition

This project presents Mohammed Sadat Abdulai's 2012 transliteration of the qunūt recited by Shaykh ʿAbdallāh Muḥammad al-Maṭrūd, in a clear, phone-friendly reading edition. The transliteration is reproduced as originally typed, spelling and all; nothing has been corrected or guessed.

Arabic script and any translation will be added later as separate, clearly labelled layers. Uncertain readings are flagged for review rather than guessed — see REVIEW.md.
