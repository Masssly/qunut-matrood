About this edition

Editorial note

This project aims to make the supplication easier to follow while listening, and to preserve the prepared text with care. The supplied document is the starting point; the recording is a comparison source, not a reason to silently change the written text.

Arabic text, transliteration, and any future translations will be labelled separately. Uncertain readings should be flagged for review rather than guessed.
